推測統計の直感的理解

この教材では、まず「ある架空の国の成人10万人の名簿」という母集団を実際に眺めるところから始めます。 そのあとのすべてのシミュレーションは、この名簿から実際に人を抜き出す（標本抽出する）ことで行います。 スライダー・数値の直接入力・［−］［＋］ボタンで値を変えられます。ソフトのインストール・ネット接続は不要です。

0. 母集団: ある国の成人10万人の名簿

ある架空の国に、20歳以上の成人がちょうど10万人（男性5万人・女性5万人）住んでいるとします。 下の表は、その全員の名簿です。1人ずつに ID がふられ、性別・身長・体重・住んでいる地域（東地域／西地域）・市町村（全部で1000市町村、各100人）・昨年1年間に外来を受診した回数が記録されています。 ページをめくったり、ID を指定したりして、一人ひとりのデータが実際に存在することを確かめてください。

※ このデータは2018年国民健康・栄養調査の平均・標準偏差に合わせて乱数で作った架空のものです。ただし全員分が固定されており、誰がいつ開いても同じ名簿になります。

名簿全員について集計した「母集団の要約統計量」は次のとおりです。以降のデモに出てくる「母平均」とは、この表の値のことです。

母集団の分布をヒストグラムで見てみましょう。身長は左右対称の釣り鐘型ですが、外来受診回数は右に裾を引いた歪んだ分布です。

1. 標本抽出の方法と標本誤差・偏り

名簿全員を調べる（全数調査）のは大変なので、一部の人を選んで調べ（標本調査）、その平均から母集団の平均（母平均）を推定します。 ここでは、次の4つの方法で標本を選び、推定値がどうなるかを比べます。

  • 単純無作為抽出: 名簿全員から、くじ引きで n 人を選ぶ
  • 系統抽出: 名簿の中で出発点をくじで決め、そこから k 人おき（k = 100,000 ÷ n）に選ぶ
  • 集落抽出: 1000の市町村（各100人）から n ÷ 100 個の市町村をくじで選び、その住民全員を調べる
  • 便宜的抽出: 病院の外来の待合室にいる人に声をかけて n 人集める（待合室で出会う確率は、その人の年間受診回数に比例するとします）
予想しよう Q1：便宜的抽出（外来の待合室）で集めた標本の平均受診回数は，母平均（約4.5回）と比べてどうなる？
確かめ方：Q3の下の操作欄で「調べる変数」を「外来受診回数（全員）」にして「100回繰り返す」を押し，表の便宜的抽出の「推定値の平均」を母平均と比べます。
解説（動かして確かめてから開こう）

答えは「大きくなる」（約2倍）。受診回数の多い人ほど待合室にいることが多いので選ばれやすく，受診0回の人は1人も選ばれません。しかも何回抽出しなおしても同じ方向にずれ，n を増やしてもずれは小さくなりません。これが偏り（バイアス）で，偶然のずれである標本誤差とは別物です。一方，調べる変数を「身長」にすると便宜的抽出でも偏りはほとんど出ません（この名簿では受診回数と身長が無関係なため）。偏りが出るかどうかは，選ばれやすさと調べたい変数が関係しているかで決まります。現実には，選ばれやすさがどの変数と関係しているかは分からないことがほとんどです。

予想しよう Q2：名簿を「男・女・男・女…」と交互に並べ替えてから，1000人おきに100人を系統抽出すると（n = 100，k = 1000），全員の平均身長（約161 cm）の推定値はどうなる？
確かめ方：Q3の下の操作欄で「調べる変数」を「身長（全員）」，「標本サイズ n」を「100人」，「系統抽出に使う名簿」を「男女交互に並べ替えた名簿」にして「100回繰り返す」を押し，系統抽出の点の分布と「最新の標本の男性の割合」を見ます。
解説（動かして確かめてから開こう）

答えは「どちらかに分かれる」。間隔 k = 1000 は偶数なので，出発点が男性なら全員男性，女性なら全員女性が選ばれます。一方，n = 800 では間隔 k = 125 が奇数になるので，男女が交互に選ばれてちょうど半々になり，この偏りは起こりません。「調べる変数」を身長，「系統抽出に使う名簿」を男女交互にして，n = 100 と n = 800 で「最新の標本の男性の割合」と点の分布を比べてみましょう。なお，n = 800 では系統抽出の推定値のばらつきが単純無作為抽出より小さくなります。男女がちょうど半々に固定され，男女比の偶然の偏りがなくなるためです（n = 100 の Q2 では，3つ目の選択肢は正解になりません）。名簿の並びに規則性があり，その周期と抽出間隔がかみ合うと，系統抽出は大きく偏ります。並びがランダムな「ID順」の名簿なら，系統抽出は単純無作為抽出とほぼ同じ結果になります。

予想しよう Q3：同じ n = 100 人を調べるとき，平均受診回数の推定値のばらつき（標準偏差）が大きいのは？
（受診回数そのもののばらつきではなく，100人のデータから推定した平均が，抽出のたびにどれだけばらつくかであることに注意）
確かめ方：下の「調べる変数」を「外来受診回数（全員）」，「標本サイズ n」を「100人」にして「100回繰り返す」を押し，表の「推定値の標準偏差（ばらつき）」を4つの方法で比べます。
解説（動かして確かめてから開こう）

答えは「集落抽出」（この名簿では約2.6倍）。同じ市町村の住民は，医療機関へのアクセスなどが共通しているため受診回数が似ています。似た人を100人集めても，実質的な情報量は100人分より少なくなります。集落抽出は名簿がなくても実施できる利点がありますが，同じ精度を得るには単純無作為抽出より多くの人数が必要です。偏りは出ないことにも注目してください（推定値の平均は母平均に一致します）。なお，このような推定値のばらつき（標準偏差）を標準誤差と呼びます。標準誤差については，このあとの「3. 中心極限定理」で詳しく扱います。

2. 大数の法則

名簿の男性5万人から、くじ引きのように何人かを選び出し（無作為抽出）、その人たちの平均身長（標本平均）を計算します。 選び出す人数 n によって、標本平均と母平均の関係はどう変わるでしょうか。

予想しよう Q4：10人の平均身長と1000人の平均身長，母平均（168.0 cm）に近いことが多いのはどちら？
確かめ方：下の「2a. 対決」で「1回対決する」や「100回まとめて」を押し，どちらの平均が母平均に近かったかの回数を数えます。
解説（動かして確かめてから開こう）

答えは「1000人の平均のほう」。ただし毎回必ず近いわけではなく，「多くの場合」近いのがポイントです。n=10 でも偶然ほぼ 168.0 cm になることはあるし，n=1000 でも少しはずれます。大数の法則は「保証」ではなく，n が大きいほどブレが小さくなるという傾向です。下の「2a. 対決」で何回も対決すると，10人の平均が勝つ回数は少ないものの，ゼロにはならないことが分かります。

3. 中心極限定理

「名簿から n 人を抽出して平均を計算する」ことを何回も繰り返し、得られた標本平均の分布をヒストグラムにします。 赤い曲線は比較のための正規分布です。 変数を「外来受診回数」（右に歪んだ分布）にして、n を 1 → 2 → 10 → 50 と増やしたとき、標本平均の分布の形とばらつきがどう変わるかを観察しましょう。

予想しよう Q5：右に歪んだ「外来受診回数」から n=50 人の平均を2000回計算したとき，標本平均のヒストグラムはどんな形になる？
確かめ方：下の「調べる変数」を「外来受診回数（全員）」，「標本サイズ n」を 50 にして，標本平均のヒストグラムの形を見ます。
解説（動かして確かめてから開こう）

答えは「左右対称の釣り鐘型」。母集団の形がどうであれ，n が大きくなると標本平均の分布は正規分布に近づき，そのばらつき（標準誤差）は σ/√n に一致します（中心極限定理）。逆に n=1 にすると標本平均の分布は母集団の形そのものになり，n=2〜5 では歪みが残ります。n を 1 から少しずつ増やして，歪みが消えていく様子を観察しましょう。

4. 信頼区間の性質

名簿の男性から n 人を抽出して 95%信頼区間を作る、という操作を何本も繰り返します。 赤い水平線が母平均（名簿の男性5万人全員の平均身長）、縦線が各標本から計算した95%信頼区間で、 母平均を含む区間は青、含まない区間は赤です。 母平均を含む区間が何本あるかを数えて、「95%信頼区間」の「95%」が何を意味しているのかを考えましょう。

予想しよう Q6：95%信頼区間を100本作ったとき，母平均を含む区間は何本くらい？
確かめ方：下の「区間の本数」を 100 にして，グラフの下に表示される「母平均を含む区間」の本数を見ます。「抽出しなおす」を何回か押しましょう。
解説（動かして確かめてから開こう）

答えは「約95本」。ただし「抽出しなおす」を押すたびに 92本になったり 98本になったりと揺らぎます。「95%」は1本1本の区間の性質ではなく，標本を取り直して区間を計算することを繰り返したときの的中率です。ここを取り違えると「母平均がこの区間に入る確率は95%」という誤読につながります。

4b. 研究者の視点 — あなたには1本しか見えない

上の図は、母集団も100本の答え合わせも見える「神の視点」でした。しかし現実の研究者が体験できるのは、このうちのたった1回分です。 「調査を1回行う」を押して、自分の調査の95%信頼区間を作ってみましょう。母平均の赤い線は表示されません——現実の研究では母平均は見えないからです。

予想しよう Q7：いまあなたが作った1本の区間は，母平均を含んでいるでしょうか？
確かめ方：下の「調査を1回行う」を押して，自分の95%信頼区間を1本作ります。
解説（何回か調査してから開こう）

答えは「確かめようがない」。そして現実の研究では答え合わせは永遠にできません。それでも研究者が信頼区間を使えるのは，無作為抽出などの前提が満たされていれば，標本平均の散らばり方が理論的に分かるからです（3節の中心極限定理）。標本平均の約95%は，母平均から標準誤差の約2倍以内に入ります。これは，「標本平均 ± 標準誤差の約2倍」の区間の約95%が母平均を含むことと同じです。論文の信頼区間を読むときは，「当たりかはずれかは分からないが，当たる確率95%のくじの結果を見ている」と考えます。下の「答え合わせ」ボタンは，このページが練習用の模型だからこそ押せる特別なボタンです。

5. 現実の研究では — このページと本物の研究の違い

このページでは、母集団の名簿がすべて見えていました。だから「母平均は 168.0 cm」と言い切れたし、100本の信頼区間の答え合わせもできました。 しかし現実の研究では、多くの場合、このようには見えません。

  • 母集団の全員を調べられるとは限らない。母集団が小さければ全員を調べられることもあります。しかし、名簿があっても、費用や労力を考えて一部だけを調べることはよくあります。全員を調べないときは、母平均の値は分からないので、標本から推測します。
  • 手にできる標本は1つだけ。このページで「抽出しなおす」を押すたびに起きていたことのうち、研究者が体験できるのは1回分だけです。自分の信頼区間が「青か赤か」（4bで体験したとおり）は永遠に分かりません。
  • 自分の区間の当たりはずれは分からなくても、作り方の的中率は理論で分かっている。信頼区間の95%は「私のこの区間が母平均を含んでいる確率」ではなく、「標本を取り直して区間を計算することを繰り返すと、そのうち約95%が母平均を含む」という作り方の的中率です。
  • 実際の研究では「名簿」がそもそも存在しないことも多い。これから来院する患者、将来起きる出来事、測るたびに揺らぐ検査値——このような場合、母集団は「データを生み出す仕組み」の比喩です。このページの名簿は、その見えない仕組みを目に見える形にした模型だと考えてください。

論文で信頼区間を読むときは、「この研究は、当たりはずれの分からないくじを1回引いた結果を報告している。ただし、無作為抽出などの前提が満たされていれば、そのくじの当たる確率は分かっている」と考えると、頻度主義統計の意味を取り違えずにすみます。
